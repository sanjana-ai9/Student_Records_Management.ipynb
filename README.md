# Student Records Management Using Python

## Description

This project is a simple student records management program created using Python. It stores student information using a dictionary.

## Features

* Store student IDs, names, and marks.
* Search for a student using their ID.
* Add new student records.
* Update student marks.
* Display all student records.

## Tools Used

* Python
* Jupyter Notebook

## Concepts Used

* Dictionaries
* Functions
* If-else conditions
* For loops

## What I Learned

Through this project, I learned how to use Python dictionaries to store student information and how to search, add, update, and display student records.

This is a beginner-level project completed as part of my Python internship task.
